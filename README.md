# MemoryMap AI

## Personal Learning Intelligence System

MemoryMap AI is an AI-powered personal learning platform that helps students learn from their own study materials.

## Features

- Upload study notes
- Store uploaded documents
- Ask questions from uploaded notes
- AI-powered answers using RAG
- Generate quizzes dynamically from study materials
- Automatic quiz scoring
- Performance analysis
- Weak-topic detection
- Revision recommendations
- Learning dashboard

## Technologies Used

- Python 3.12
- Streamlit
- Ollama
- Llama 3.2
- Sentence-Transformers
- NumPy
- Pandas
- Requests
- RAG
